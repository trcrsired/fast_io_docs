2|第11.10.4章: fast_io 中的协议支持
3|与主要聚焦 TCP 和 UDP 的 Boost.Asio 不同，<code>fast_io</code> 的 socket API 通过操作系统的原生 socket 接口支持广泛的协议：
4|<strong>TCP</strong> &mdash; 可靠的、面向连接的流（最常用）
5|<strong>UDP</strong> &mdash; 不可靠的、无连接的数据报（快、开销低）
6|<strong>Unix 域套接字</strong> &mdash; 本地进程间通信（POSIX）
7|<strong>蓝牙</strong> &mdash; 蓝牙 socket（在操作系统支持时）
8|<strong>原始套接字</strong> &mdash; 直接访问 IP/ICMP 等（需要 root/管理员权限）
9|<strong>其他协议</strong> &mdash; 操作系统 socket API 支持的任何协议
10|关键差别在于：<code>fast_io</code> 直接包装操作系统的 socket 接口，因此你能用到操作系统支持的<em>一切</em>。你不会被限制在一份硬编码的协议清单上。
11|对 TCP 与 UDP，<code>fast_io</code> 提供 <code>tcp_connect()</code>、<code>tcp_listen()</code> 以及 DNS 解析这样的便捷函数。对其他协议，你可以直接从操作系统的 socket 句柄构造 socket 文件。
