3|概述
4|本附录记录所有字符串特有的操作。需要某个功能时再回来查。
5|1. npos
6|<code>::fast_io::containers::npos</code> 定义为 <code>::std::numeric_limits&lt;::std::size_t&gt;::max()</code>。它有两个用途：
7|<strong>“未找到”</strong> &mdash; 所有 <code>find*</code> 操作在查找失败时返回它。
8|<strong>“直到末尾”</strong> &mdash; <code>subview()</code>、<code>substr()</code> 的默认 <code>count</code> 参数，表示“到字符串末尾”。
9|2. 查找操作
10|所有查找操作都返回 <code>size_type</code>，找不到目标时返回 <code>npos</code>。

51|<code>subview*</code> 返回<strong>非拥有视图</strong>（<code>string_view</code>）；<code>substr*</code> 返回<strong>拥有所有权的副本</strong>（<code>string</code>）。

133|7. 比较
134|字符串和字符串视图支持 <code>==</code> 与 <code>&lt;=&gt;</code>（C++20 三路比较）。比较按字典序进行。
135|8. c_str()
136|<code>c_str()</code> 返回以空字符结尾的 <code>const char*</code>，用于与 C API 交互。由于 <code>fast_io::string</code> 始终以空字符结尾，这是一次 &Theta;(1) 的指针返回。
137|9. resize_and_overwrite()
138|C++23 风格的方法：把字符串调整到给定大小，然后用指向原始缓冲区的指针调用用户回调。适合从 C API 或自定义逻辑填充字符串，而无需额外复制。
