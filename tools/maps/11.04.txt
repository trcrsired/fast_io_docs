3|概述
4|所有底层 I/O 操作都在 <code>::fast_io::operations</code> 命名空间中。它们作用于设备与原始缓冲区之间，构成 <code>print</code>、<code>scan</code> 与带缓冲文件类型建立于其上的那一层。
5|1. read_some / read_all
6|<code>read_some</code> 尝试从设备读入一段连续缓冲区。它<strong>可能只读取一部分</strong>，并返回最后读到的那个字节之后的位置。
7|<code>read_all</code> 在内部循环，直到缓冲区被完全填满，或者遇到 EOF/错误为止。
8|2. read_some_bytes / read_all_bytes
9|与 <code>read_some</code> / <code>read_all</code> 相同，但作用于 <code>::std::byte*</code>。
10|3. pread_some / pread_all
11|<strong>按位置读取</strong> &mdash; 在给定的文件偏移处读取，而不改变文件位置。
12|签名多了一个 <code>offset</code> 参数（从文件开头算起的字节数）。
13|4. pread_some_bytes / pread_all_bytes
14|与 <code>pread_some</code> / <code>pread_all</code> 相同，但接受 <code>::std::byte*</code>。
15|5. scatter_read_some / scatter_read_all
16|<strong>散布（聚集）读取</strong>在一次系统调用中读入多个不连续的缓冲区。
17|参数是一个 <code>::fast_io::io_scatter_t</code> 的 span，每一项描述一个 base/length 对。
18|6. scatter_pread_some / scatter_pread_all
19|把散布读取与按位置读取结合起来 &mdash; 从给定偏移处读入多个缓冲区。
20|8. write_some / write_all
21|<code>write_some</code> 尝试把一段连续缓冲区写入设备。它<strong>可能只写入一部分</strong>，并返回第一个未写出的位置。
22|<code>write_all</code> 在内部循环，直到每个字节都被写出，或者发生硬错误为止。
23|9. write_some_bytes / write_all_bytes
24|与 <code>write_some</code> / <code>write_all</code> 相同，但作用于 <code>::std::byte const*</code>。
25|10. pwrite_some / pwrite_all
26|<strong>按位置写入</strong> &mdash; 在给定的文件偏移处写入，而不改变文件位置。
27|签名多了一个 <code>offset</code> 参数（从文件开头算起的字节数）。
28|11. pwrite_some_bytes / pwrite_all_bytes
29|与 <code>pwrite_some</code> / <code>pwrite_all</code> 相同，但接受 <code>::std::byte const*</code>。
30|12. scatter_write_some / scatter_write_all
31|<strong>散布（聚集）写入</strong>在一次系统调用中写出多个不连续的缓冲区。
32|参数是一个 <code>::fast_io::io_scatter_t</code> 的 span，每一项描述一个 base/length 对。
33|13. scatter_pwrite_some / scatter_pwrite_all
34|把散布写入与按位置写入结合起来 &mdash; 在给定偏移处写出多个缓冲区。
35|14. char_put
36|写出单个字符。所有写变体都有对应的 <code>char_put</code> 版本，用于逐字符写入。
37|对带缓冲的设备（<code>obuf_file</code>），反复调用 <code>char_put</code> 很便宜；对不带缓冲的设备则代价极高。

194|要点
195|<code>read_some</code> 可能只做部分读取 &mdash; 它返回最后读到的字节之后的位置。
196|<code>write_some</code> 可能只做部分写入 &mdash; 它返回第一个未写出的位置。
197|每个操作都有一个 <code>_bytes</code> 变体，接受 <code>::std::byte*</code>（以及对应的 <code>::std::byte const*</code>）。
198|<code>pread_*</code> 系列在给定偏移处读取，而不改变文件位置。
199|<code>pwrite_*</code> 系列在给定偏移处写入，而不改变文件位置。
200|<code>scatter_read_*</code> 在一次系统调用中读入多个缓冲区（类似 POSIX 的 <code>readv</code>）。
201|<code>scatter_write_*</code> 在一次系统调用中写出多个缓冲区（类似 POSIX 的 <code>writev</code>）。
202|<code>scatter_pread_*</code> 与 <code>scatter_pwrite_*</code> 把散布与按位置操作结合起来。
203|<code>char_put</code> 写出单个字符 &mdash; 在带缓冲设备上便宜，在不带缓冲设备上灾难性地昂贵。
204|优先使用 <code>read_all</code> / <code>write_all</code>（或者带缓冲的 <code>::fast_io::io::</code> 设施），而不是自己循环 <code>read_some</code> / <code>write_some</code>。
