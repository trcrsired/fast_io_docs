第3章: 语句

English

概述

本章介绍 C++ 基本的控制流语句： 条件、循环、分支以及结构化控制结构。 这些语句决定你的程序如何执行，以及如何对数据做出反应。

本章以 第3.16章 收尾，讲授 fast_io 中错误是如何报告的——这是后续每一章都会用到的机制。

  • 第3.16章: 赫布异常
    • fast_io 中的每个错误都是赫布异常。本小节讲授 throw throws、catch throws、构建选项，以及 错误域。

要点

  • 语句是控制流的骨架；后面每一章都建立在它上面。
  • 优先用 if、for 和 while，少用 goto；switch 的贯穿要写清楚。
  • 预处理器用于配置和特性测试，不用于程序逻辑。
  • fast_io 用 herbception 报错：throw throws 和 catch throws。
