第1.2章: VS Code（PWA）

English

Visual Studio Code（VS Code）提供了渐进式 Web 应用（PWA）版本。 这让你可以直接在浏览器中运行 VS Code，外观和体验都与桌面版相同。

我们使用 Microsoft Edge，因为它在 Windows、macOS、Android 和 Linux 上拥有最好的 PWA 支持。 不要使用 Firefox 或 Safari —— 它们不支持文件系统访问，而 VS Code PWA 需要该能力才能正常工作。

通过 PWA 应用商店安装

打开 PWA 应用商店，在 “搜索应用……” 输入框中键入 vscode。 使用 PWA 应用商店打开 Visual Studio Code 或 VS Code Insider 的网站。 然后，使用与我们安装 PWA 应用商店本身相同的方法： 点击 Microsoft Edge 地址栏右侧的 “安装应用” 按钮。

直接安装

你也可以直接访问以下网址来安装 VS Code：

  • VS Code 稳定版（PWA）
  • VS Code Insiders（PWA）

不过，PWA 应用商店更方便，因为它在一处就提供了对许多其他应用的访问。

关闭自动保存

将 VS Code 作为 PWA 安装后，请关闭 自动保存 功能。 由于文件系统权限受限，自动保存在 PWA 中可能会出问题，并且可能无法正确工作。

  1. 打开 VS Code（PWA）。
  2. 进入 File → Auto Save。
  3. 取消勾选该选项以关闭它。
