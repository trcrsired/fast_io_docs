第14.7章: swap：交换两个拥有者

English

1. swap 必须做什么

对资源拥有者来说，swap 交换的是两个对象各自拥有的资源。它不复制、不关闭、不分配：它交换两个句柄。 


	void swap(my_posix_file &other) noexcept
	{
		::std::int_least32_t const tmp{fd_};
		fd_ = other.fd_;
		other.fd_ = tmp;
	}

三次 int 写入加一个临时变量。它不会失败，所以它是 noexcept — 而这不是细节：正是 swap 的 noexcept 让复制并交换给出强保证。

2. 自由函数，以及它为什么存在

对 a.swap(b) 来说成员函数就够了。自由函数是让裸的 swap(a, b) 能工作的东西： 


inline void swap(my_posix_file &a, my_posix_file &b) noexcept
{
	a.swap(b);
}

它住在与类相同的命名空间里，实参依赖查找（第13.10章）会在那里找到它。于是说 swap(x, y)（而不是 ::std::swap(x, y)）的泛型代码，在类型有自己的版本时选中你的，否则退回 ::std::swap。两个都写：成员函数干活，自由函数让名字可被找到。

3. 没有你的版本时 ::std::swap 做什么

标准的 ::std::swap 是用一次移动加两次移动赋值实现的： 


template <typename T>
void swap(T &a, T &b) noexcept(...)
{
	T tmp{::std::move(a)};
	a = ::std::move(b);
	b = ::std::move(tmp);
}

对我们的类来说那是三次描述符交换，所以结果相同 — 下面的程序用了三种写法，每种打印出的数字都一样。它正确，仅仅因为移动操作是 noexcept，并且移动赋值释放了它该释放的东西；如果其中任何一个错了，::std::swap 也就错了，而且错在离 bug 很远的地方。 


#include <fast_io.h>
#include <fast_io_dsal/string_view.h>

using namespace ::fast_io::io;

class my_posix_file
{
	int fd_{-1};

	void reset(::std::int_least32_t newfd = -1) noexcept
	{
		if (fd_ != -1)
		{
			::close(fd_);
		}
		fd_ = newfd;
	}

public:
	my_posix_file() noexcept = default;

	explicit my_posix_file(::fast_io::cstring_view path, ::std::int_least32_t flags) throws
	{
		::std::int_least32_t fd{::open(path.c_str(), flags, 0644)};
		if (fd == -1) [[unlikely]]
		{
			throw throws static_cast<::std::errc>(errno);
		}
		fd_ = fd;
	}

	my_posix_file(my_posix_file const &) = delete;
	my_posix_file &operator=(my_posix_file const &) = delete;

	my_posix_file(my_posix_file &&other) noexcept : fd_{other.fd_}
	{
		other.fd_ = -1;
	}

	my_posix_file &operator=(my_posix_file &&other) noexcept
	{
		if (this == ::std::addressof(other)) [[unlikely]]
		{
			return *this;
		}
		reset(other.fd_);
		other.fd_ = -1;
		return *this;
	}

	~my_posix_file() noexcept
	{
		reset();
	}

	void swap(my_posix_file &other) noexcept
	{
		::std::int_least32_t const tmp{fd_};
		fd_ = other.fd_;
		other.fd_ = tmp;
	}

	[[nodiscard]] bool is_open() const noexcept
	{
		return fd_ != -1;
	}

	[[nodiscard]] ::std::int_least32_t native_handle() const noexcept
	{
		return fd_;
	}
};

inline void swap(my_posix_file &a, my_posix_file &b) noexcept
{
	a.swap(b);
}

static_assert(::std::is_nothrow_swappable_v<my_posix_file>);

int main()
{
	{ // make sure the example file exists
		::std::int_least32_t fd{::open("demo.txt", O_WRONLY | O_CREAT, 0644)};
		::close(fd);
	}

	my_posix_file a{"demo.txt", O_RDONLY};
	my_posix_file b{"demo.txt", O_WRONLY};
	println("a = ", a.native_handle(), ", b = ", b.native_handle());

	a.swap(b);
	println("after a.swap(b):               a = ", a.native_handle(), ", b = ", b.native_handle());

	swap(a, b);
	println("after swap(a, b):              a = ", a.native_handle(), ", b = ", b.native_handle());

	::std::swap(a, b);
	println("after ::std::swap(a, b):       a = ", a.native_handle(), ", b = ", b.native_handle());

	my_posix_file empty;
	a.swap(empty);
	println("after a.swap(empty):           a = ", a.native_handle(), ", empty = ", empty.native_handle());
	println("a.is_open() = ", a.is_open(), ", empty.is_open() = ", empty.is_open());
}


a = 3, b = 4
after a.swap(b):               a = 4, b = 3
after swap(a, b):              a = 3, b = 4
after ::std::swap(a, b):       a = 4, b = 3
after a.swap(empty):           a = -1, empty = 4
a.is_open() = 0, empty.is_open() = 1

读最后两行：与一个默认构造的（空的）对象交换，就是你释放一个资源并把它保存在别处的办法。a 最终什么都不拥有，empty 拥有那个文件；empty 消亡时文件关闭。这个技巧值得记住 — 它就是你把资源停放在一个局部对象里、让析构函数去处理的办法。

4. 检查它真的不会失败

::std::is_nothrow_swappable_v 是一个有编译期答案的编译期问题，也正是容器和算法所检验的性质： 


static_assert(::std::is_nothrow_swappable_v<my_posix_file>);

如果你把 swap 写成复制式的 — 例如 my_posix_file tmp{other}; other = *this; *this = tmp; — 那个断言就会失败，因为复制一个文件可能失败，而这理所应当。

5. swap 是提交原语

复制赋值（第14.4章）在临界线之后以一条不会失败的语句结束。对一个只有一个资源的类来说，那条语句是 reset(newfd)。对有多个成员的类来说，没有单一的 reset，但总有一个 swap — 那就是下一个子章的主题。
