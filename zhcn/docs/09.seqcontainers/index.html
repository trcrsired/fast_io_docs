第9章: 序列容器

English

概述

本章扩展第4章（dsal）中的内容，并涵盖 fast_io_dsal 中提供的所有序列容器。

序列容器中元素的顺序与元素加入的先后顺序一致：第一个加入的元素位于位置 0，第二个位于位置 1，依此类推。这与关联容器（第10章）不同——关联容器根据与每个元素相关联的键来存放元素。

这些容器类共享一套通用接口。你学到的一种容器的用法同样适用于另一种。每种容器在性能与功能上提供不同的取舍。

默认容器是 ::fast_io::vector。除非你有明确的理由使用别的容器，否则就用 vector。

要点

  • 顺序容器在布局、访问代价和迭代器失效规则上不同。
  • vector 是默认选择；deque、list 和 forward_list 服务于特定访问模式。
  • 迭代器是左闭范围，失效规则是 API 的一部分。
  • 在性能分析证明必要之前，优先用带检查的操作。
