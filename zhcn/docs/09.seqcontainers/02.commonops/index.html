第9.2章: 通用操作

English

概述

所有序列容器共享一大套通用操作。本节用完整的表格说明每项操作做什么、怎么用，以及哪些容器支持它。✓ 表示支持；— 表示不可用；加了注释则表示该操作存在，但语义有所不同。

2. 容量操作

这些操作用于查询或调整容器在不重新分配的情况下能容纳的元素个数。

4. 迭代器操作

这些操作返回用于界定容器元素范围的迭代器。所有迭代器都遵循左闭约定：范围 [begin(), end()) 包含第一个元素，但不包含末尾之后的位置。

操作 说明 示例 vector deque list forward_list array span string_view
begin() / end() 返回指向第一个元素的迭代器 / 指向最后一个元素之后位置的迭代器。 for (auto it = v.begin(); it != v.end(); ++it) ✓✓✓✓ ✓✓✓
cbegin() / cend() 返回 const 迭代器。通过该迭代器无法修改元素。 for (auto it = v.cbegin(); it != v.cend(); ++it) ✓✓✓✓ ✓✓✓
rbegin() / rend() 返回反向迭代器，从最后一个元素遍历到第一个元素。 for (auto it = v.rbegin(); it != v.rend(); ++it) ✓✓✓✓ ✓✓✓
before_begin() 返回指向第一个元素之前位置的迭代器。只有 forward_list 提供它，用于在头部插入。 fl.insert_after(fl.before_begin(), val); ———✓ ———

这些操作在容器中添加、删除或替换元素。

要点

  • 所有容器在大小、遍历与元素访问方面共享一套通用接口。
  • list 和 forward_list 不提供 size()；forward_list 还没有 back()。
  • list 和 forward_list 不支持 operator[]，也不支持随机访问。
  • 只有 vector、deque、array 以及连续视图提供 data()。
  • clear() 保留容量；clear_destroy() 释放内存。
  • deque 是唯一同时具备 push_front() 和双端容量的容器。
