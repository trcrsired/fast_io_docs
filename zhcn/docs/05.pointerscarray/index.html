第5章: 指针与 C 风格数组

概述

本章介绍 C++ 中三个紧密相关的概念： 指针、C 风格数组和 C 风格字符串。 它们频繁出现在已有的 C 和 C++ 代码、库以及示例中。

前面的章节聚焦于更安全的容器，例如 ::fast_io::vector、::fast_io::string 和 ::fast_io::array。在本章中，你将学到：

  • 什么是地址，以及指针如何指向对象
  • C 风格数组与 C 风格字符串是如何表示的
  • 指针算术与索引之间的关系
  • 如何把指针与 ::fast_io::vector、::fast_io::array 和 ::fast_io::string 联系起来

一个主要目标，是展示指针如何自然地融入你从第4章已经熟悉的容器模型。
