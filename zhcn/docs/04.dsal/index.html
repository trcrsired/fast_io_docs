第4章: 数据结构与算法

English

概述

fast_io 中的 dsal 模块提供了一组 简单、可预测的容器。这些容器构成了在你的程序中存储与组织数据的 基础。

在本章中，你将学到：

  • ::fast_io::string 如何存储并增长字符序列
  • ::fast_io::vector 如何管理可增长的元素序列
  • ::fast_io::array 如何提供固定大小的序列
  • 如何通过嵌套容器来构建二维、三维乃至更高维的结构

这四个容器为你处理数据序列打下了坚实基础。 它们也为第5章做好了准备，在那里你将学到 指针如何与这些容器交互。
