第12.1章: C++ 随机引擎

English

概述

C++ 在 <random> 头文件中提供若干随机数引擎。这些引擎基于初始种子生成伪随机序列。最常用的引擎有：

  • ::std::mt19937 — 32 位梅森旋转（Mersenne Twister）
  • ::std::mt19937_64 — 64 位梅森旋转
  • ::std::minstd_rand — 线性同余引擎
  • ::std::ranlux48 — 带进位减法引擎

梅森旋转引擎（mt19937 与 mt19937_64）因其优异的统计性质与超长周期（219937-1）而使用最广。

使用 std::mt19937_64

64 位梅森旋转适用于大多数需要随机数的应用。用法如下： 


#include <fast_io.h>
#include <random>

int main() {
    using namespace ::fast_io::io;

    // Create an engine with default seed
    // WARNING: This is predictable! Always use proper seeding.
    ::std::mt19937_64 eng;

    // Generate random numbers
    for (::std::size_t i{}; i != 10; ++i) {
        println("Random: ", eng());
    }
}
警告：使用默认构造函数会产生可预测的序列。默认种子是固定的（通常是 5489u），因此每次运行程序都会产生同样的“随机”数。请始终用 ::std::seed_seq 配合安全来源做正规播种（见第12.4章）。

引擎的通用属性

所有 C++ 随机引擎都提供这些方法：

方法 说明
operator()() 生成序列中的下一个随机数
min() 返回引擎能产生的最小值
max() 返回引擎能产生的最大值
seed() 用新的种子值重新播种引擎
discard(z) 把引擎状态前进 z 步而不产生输出

引擎对比

引擎 输出类型 周期 适用场景
::std::mt19937 32 位无符号 219937-1 通用、游戏、仿真
::std::mt19937_64 64 位无符号 219937-1 通用、状态空间更大
::std::minstd_rand 32 位无符号 231-1 简单、快，但质量较低
::std::ranlux48 48 位无符号 ~10171 高质量，但较慢

要点

  • C++ 在 <random> 中提供若干随机引擎，其中 ::std::mt19937_64 最常用。
  • 引擎基于初始种子生成伪随机序列。
  • 对重要应用绝不要使用默认构造函数 — 它产生的序列是可预测的。
  • 请始终用安全来源的数值配合 ::std::seed_seq 正确播种（见第12.4章）。
  • 需要密码学安全的随机性时，使用 ::fast_io::ibuf_white_hole_engine（见第12.3章）。
