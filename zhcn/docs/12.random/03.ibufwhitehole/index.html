第12.3章: ibuf_white_hole_engine

English

什么是 ibuf_white_hole_engine？

::fast_io::ibuf_white_hole_engine 是一个密码学安全的随机数引擎，直接读取操作系统的熵源。“白洞”这个名字是个比喻：黑洞吸收一切，而白洞则喷出随机字节。

这个引擎满足 C++ 的 UniformRandomBitGenerator 要求，因此能与 <random> 中的所有分布无缝配合，例如 ::std::uniform_int_distribution、::std::bernoulli_distribution 等。

关键特性

  • 带缓冲 I/O：一次从操作系统熵源读取 8 KB，摊薄系统调用开销。大多数生成随机数的调用只是一次指针移动加一次 memcpy — 没有系统调用。
  • 安全清空内存：引擎销毁时内部缓冲区被安全擦除，保护密码学密钥材料。
  • 自动选择平台：为你的平台使用最佳的可用熵源（getrandom()、/dev/urandom、RtlGenRandom 等）。
  • 符合标准：可与 <random> 中的任何 C++ 分布配合。
  • 线程安全：每个引擎实例相互独立。多个线程可以使用各自的引擎实例而无需同步。

基本用法


#include <fast_io.h>
#include <fast_io_device.h>
#include <random>

int main() {
    using namespace ::fast_io::io;

    // Create a cryptographically secure random engine
    ::fast_io::ibuf_white_hole_engine eng;

    // Use with uniform_int_distribution
    ::std::uniform_int_distribution<::std::uint32_t> dist(1, 100);

    // Generate random numbers
    for (::std::size_t i{}; i != 10; ++i) {
        println("Random number in [1, 100]: ", dist(eng));
    }

    // Use with bernoulli_distribution for true/false
    ::std::bernoulli_distribution coin_flip(0.5);
    for (::std::size_t i{}; i != 5; ++i) {
        bool heads = coin_flip(eng);
        println("Coin flip: ", ::fast_io::mnp::os_c_str(heads ? "heads" : "tails"));
    }
}

相关主题

ibuf_white_hole_engine 也能配合 ::std::shuffle 做密码学安全的容器洗牌。详见第12.5章: 用 std::shuffle 洗牌。

它是如何实现的

这个引擎是以类型别名实现的： 


using ibuf_white_hole_engine = basic_white_hole_engine<ibuf_white_hole>;

其中 ibuf_white_hole 是平台专用随机源之上的输入缓冲包装。缓冲模式包含 buffer_mode::secure_clear，确保缓冲区在销毁时被擦除。

operator()() 方法从带缓冲的来源读取 sizeof(::std::size_t) 个字节，并作为 ::std::size_t 返回。大多数调用由缓冲区直接满足，不发生系统调用。

用 ibuf_white_hole 读取原始字节

如果你需要原始随机字节（例如创建密码学密钥或 token），可以直接把 ::fast_io::ibuf_white_hole 当作输入流使用： 


#include <fast_io.h>
#include <fast_io_device.h>
#include <array>

int main() {
    using namespace ::fast_io::io;

    // Create a buffered white hole (input stream)
    ::fast_io::ibuf_white_hole rng;

    // Read 32 random bytes
    ::fast_io::array<::std::byte, 32> buffer;
    ::fast_io::operations::read_all(rng, buffer.data(), buffer.data() + buffer.size());

    // Print as hex
    println("Random bytes (hex):");
    for (::std::size_t i{}; i != buffer.size(); ++i) {
        print(::fast_io::mnp::hex(::fast_io::mnp::upper(buffer[i])), " ");
        if ((i + 1) % 16 == 0) {
            print("\n");
        }
    }

    // Use for generating a UUID (16 bytes)
    ::fast_io::array<::std::byte, 16> uuid_bytes;
    ::fast_io::operations::read_all(rng, uuid_bytes.data(), uuid_bytes.data() + uuid_bytes.size());

    println("\nUUID bytes:");
    for (::std::size_t i{}; i != uuid_bytes.size(); ++i) {
        print(::fast_io::mnp::hex(uuid_bytes[i]));
        if (i == 3 || i == 5 || i == 7 || i == 9) {
            print('-');
        }
    }
    print("\n");
}

ibuf_white_hole 是底层的输入流类型。它通过标准 I/O 接口（read_all、read_some 等）提供与引擎相同的、带缓冲的密码学安全随机字节。

一次性使用：native_white_hole

如果你只需要生成一次随机字节（例如创建一个密钥或 token），请使用 ::fast_io::native_white_hole 而不是 ibuf_white_hole。native_white_hole 不带缓冲、直接发起系统调用，在你不会复用这个流时更高效。 


#include <fast_io.h>
#include <fast_io_device.h>
#include <array>

int main() {
    using namespace ::fast_io::io;

    // Generate a single API key (32 bytes)
    ::fast_io::native_white_hole rng;
    ::fast_io::array<::std::byte, 32> api_key;
    ::fast_io::operations::read_all(rng, api_key.data(), api_key.data() + api_key.size());

    // Guard ensures api_key is securely cleared when it goes out of scope
    ::fast_io::secure_clear_guard guard(api_key.data(), api_key.size());

    println("Generated API key (32 bytes)");

    // No need to keep rng around - we only used it once
    // The unbuffered approach is more efficient for one-time use
    // api_key will be securely cleared automatically when guard is destroyed
}
重要：请始终使用 ::fast_io::secure_clear_guard，在 API 密钥、token 或密码学密钥等敏感数据离开作用域时自动把它们从内存中擦除。这个 RAII 守卫防止秘密通过内存转储、交换文件或调试工具泄漏，即使发生异常也一样。

什么时候用 native_white_hole，什么时候用 ibuf_white_hole：

  • 一次性生成秘密、密钥或 token，且不会复用该流时，用 native_white_hole。没有缓冲开销。
  • 当你需要在一段时间内多次取得随机值时，用 ibuf_white_hole 或 ibuf_white_hole_engine。8KB 缓冲区摊薄了系统调用开销。

什么时候使用

在下列情况下使用 ibuf_white_hole_engine：

  • 你需要密码学安全的随机数
  • 生成密码学密钥、token 或会话 ID
  • 为密码加盐
  • 任何安全敏感的应用
  • 你不需要可复现的随机性

需要可复现的随机性（调试、测试、仿真）时，见第12.4章: 为可复现引擎播种。

要点

  • ibuf_white_hole_engine 是密码学安全、带缓冲的随机引擎，会自动使用最佳的平台专用熵源。
  • 它满足 UniformRandomBitGenerator 要求，可直接配合所有 C++ 分布使用。
  • 8 KB 缓冲区摊薄了系统调用开销，因此尽管从操作系统读取依然很快。
  • 缓冲区在销毁时被安全清空，保护敏感数据。
  • 在需要不可预测性的安全敏感应用中使用它。
