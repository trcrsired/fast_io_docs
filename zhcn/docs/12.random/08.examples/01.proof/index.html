第12.8.1章: 数学证明 — 为什么“生到有男孩为止”不影响性别比

English

概述

直觉上似乎会觉得：如果每个家庭都一直生到有男孩为止，那么男孩会比女孩多。但这在数学上是错的。下面是证明。

设定

设 p 为生男孩的概率（约 0.507），q = 1 - p 为生女孩的概率（约 0.493）。每次出生都是独立事件。

每个家庭的期望值

用几何分布，我们可以算出每个家庭的期望孩子数：

  • 每个家庭的期望男孩数：每个家庭在恰好有 1 个男孩时停止，所以 E[男孩] = 1
  • 每个家庭的期望女孩数：第一个男孩之前的女孩数服从几何分布，期望值为 E[女孩] = q/p
  • 每个家庭的期望孩子总数：E[总数] = E[男孩] + E[女孩] = 1 + q/p = (p + q)/p = 1/p

人口层面的性别比

对 N 个家庭，期望的总量为：

  • 男孩总数 = N × 1 = N
  • 女孩总数 = N × (q/p)
  • 孩子总数 = N × (1/p)

性别比（每 100 名女性对应的男性数）为： 


Sex Ratio = (Total boys / Total girls) × 100
          = (N / (N × q/p)) × 100
          = (p/q) × 100
          = (0.507 / 0.493) × 100
          ≈ 102.84:100

这正是自然的性别比！停止规则并不改变它。

直观解释

每个出生的男孩都“抵消”了一个停止生育的家庭。那个男孩之前出生的女孩，被另一些家庭在得到男孩之前生了很多女孩这一事实所平衡。期望女孩数（q/p）完美补偿了我们总是恰好得到一个男孩这一点。

在数学上，男孩占全部出生的比例是： 


P(boy) = E[boys] / E[total] = 1 / (1/p) = p

而这正是男孩出生的自然概率！

大数定律

当人口规模 N 趋于无穷时，实际比例依大数定律收敛到期望值。这就是为什么我们那一亿个家庭的模拟恰好显示 103.00:100 — 它几乎完美地符合自然概率。

结论

“生到有男孩为止”的策略不影响出生性别比。无论采取什么停止规则，比例都保持在约 103:100 的自然生物男女比。这是概率论与大数定律的一个基本结论。
