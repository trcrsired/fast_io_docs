示例 1：密码生成器

这个示例生成 12 到 20 个字符长度的随机密码，使用字母数字字符（0-9、a-z、A-Z）。它展示了如何同时使用多个分布，并把随机值映射到字符集合。

源码：examples/0014.random/password.cc 


#include <fast_io.h>
#include <fast_io_device.h>
#include <random>

using namespace fast_io::io;

int main(int argc, char **argv)
{
    ::std::size_t n{100};
    if (1 < argc)
    {
        n = fast_io::to<::std::size_t>(fast_io::mnp::os_c_str(argv[1]));
    }

    fast_io::u8obuf_file obf(u"password.txt");
    fast_io::ibuf_white_hole_engine eng;

    // Distribution for character selection (0-61 maps to 62 characters)
    ::std::uniform_int_distribution<::std::size_t> ud(0, 61);

    // Distribution for password length (12-20 characters)
    ::std::uniform_int_distribution<::std::size_t> rlen(12, 20);

    for (::std::size_t i{}; i != n; ++i)
    {
        // Generate a password of random length
        for (::std::size_t j{}, s(rlen(eng)); j != s; ++j)
        {
            char8_t ch(static_cast<char8_t>(ud(eng)));

            // Map 0-9 to '0'-'9'
            if (ch < 10u)
            {
                ch += u8'0';
            }
            // Map 10-35 to 'a'-'z'
            else if (ch < 36u)
            {
                ch = ch - 10u + u8'a';
            }
            // Map 36-61 to 'A'-'Z'
            else
            {
                ch = ch - 36u + u8'A';
            }

            print(obf, fast_io::mnp::chvw(ch));
        }
        println(obf);
    }
}

要点：

  • 使用两个分布：一个用于选择字符，一个用于决定密码长度。
  • 把 [0, 61] 的均匀分布映射到字符区间（数字、小写、大写）。
  • 每个密码的长度在 12 到 20 个字符之间随机。
  • 使用 ibuf_white_hole_engine 获得密码学安全的随机性。

示例 2：用伯努利分布模拟出生

这个示例模拟这样的情形：父母一直生孩子直到有了一个男孩。它使用自然的男女出生比例（约 1.03:1），并演示用 bernoulli_distribution 对给定概率的二值结果建模。

源码：examples/0014.random/stop_born_child_until_boy.cc 


#include <random>
#include <fast_io.h>
#include <map>

using namespace fast_io::io;

int main(int argc, char **argv)
{
    using namespace fast_io::mnp;

    if (argc < 2)
    {
        if (argc == 0)
        {
            return 1;
        }
        perr("Usage: ", os_c_str(*argv), " N\n");
        return 1;
    }

    // Natural male-to-female ratio is approximately 1.03:1
    constexpr auto natural_male_to_female_ratio{1.03};
    constexpr auto total_ratio{natural_male_to_female_ratio + 1.0};
    constexpr auto male_probability{natural_male_to_female_ratio / total_ratio};

    fast_io::ibuf_white_hole_engine engine;

    // Bernoulli distribution with probability of male birth
    ::std::bernoulli_distribution dis(male_probability);

    ::std::uint_least64_t const n{::fast_io::to<::std::uint_least64_t>(os_c_str(argv[1]))};
    ::std::map<::std::uint_least64_t, ::std::uint_least64_t> map;
    ::std::uint_least64_t total_population{};

    // Simulate n families
    for (::std::uint_least64_t i{}; i != n; ++i)
    {
        ::std::uint_least64_t j{1};

        // Keep having children until a boy is born
        for (; !dis(engine); ++j)
            ;

        ++map[j];
        total_population += j;
    }

    fast_io::out_buf_type obf(fast_io::out());

    // Print distribution of family sizes
    for (auto const &e : map)
    {
        print(obf, e.first, " ", e.second, " (",
              percentage_conventional(e.second, n), ")\n");
    }

    ::std::uint_least64_t const females{total_population - n};
    println(obf, "males:", n, "\tfemales:", females,
            "\n"
            "total population:",
            total_population,
            "\n"
            "Sex Ratio:",
            percentage_sex_ratio(n, females));
}

要点：

  • 使用概率约为 0.507 的 bernoulli_distribution（自然的男孩出生率）。
  • 模拟家庭一直生育直到有男孩为止。
  • 统计每个家庭有多少孩子并计算统计量。
  • 演示如何用分布做统计仿真。

运行这些示例

编译并运行这些示例： 


# Compile password generator
g++ -std=c++20 -O2 -o password password.cc -I/path/to/fast_io/include

# Generate 50 passwords
./password 50

# Compile birth simulation
g++ -std=c++20 -O2 -o birth_sim stop_born_child_until_boy.cc -I/path/to/fast_io/include

# Simulate 10000 families
./birth_sim 10000

百分比操纵器参考

上面的示例使用了 fast_io::mnp 中若干与百分比相关的操纵器。完整参考如下：

操纵器 说明 示例输出
percentage_conventional(num, den) 计算 num/den * 100，并按保留两位小数的百分比格式化 percentage_conventional(1, 4) → 25.00%
与上面相同，但使用逗号作为小数分隔符 Same as above, but uses comma as decimal separator comma_percentage_conventional(1, 4) → 25,00%
percentage_sex_ratio(male, female) 把男女比例计算为 X.XX:100 形式（每 100 名女性对应的男性数） percentage_sex_ratio(103, 100) → 103.00:100
comma_percentage_sex_ratio(male, female) 与上面相同，但使用逗号作为小数分隔符 comma_percentage_sex_ratio(103, 100) → 103,00:100
base_percentage_conventional<base>(num, den) 以其他进制（2-36）表示的百分比 base_percentage_conventional<16>(1, 4) → 19.00%
base_percentage_sex_ratio<base>(male, female) 以其他进制（2-36）表示的性别比 base_percentage_sex_ratio<16>(103, 100) → 67.00:100

模板参数：所有操纵器都接受可选的模板参数 <uppercase, full, showpos> 来控制格式化。

要点

  • 真实世界的应用往往要组合多个分布（用均匀分布选元素、用均匀分布定大小、用伯努利分布处理二值结果）。
  • ibuf_white_hole_engine 提供密码学安全的随机性，适合生成密码。
  • bernoulli_distribution 这样的分布让具有特定概率的随机事件极易建模。
  • 把均匀分布映射到字符集合是密码生成器中的常见模式。
  • 统计仿真受益于使用正确的分布，而不是手动变换。
  • 性别比误解：上面的模拟表明，即使每个家庭都一直生到有男孩为止，出生时的总体性别比仍保持在自然比例（约 103:100 男比女）。这是一个常见的误解 — 停止规则不影响底层的概率。在大样本中，这个比例总会收敛到自然生物比例。现实中造成性别比失衡的真正原因是性别选择性流产、溺杀女婴以及其他性别选择技术，而不是家庭生育计划。
  • 晚来的男孩只是概率：示例输出显示，有些家庭的第一个男孩是第 10 个、第 15 个，甚至第 29 个孩子。这不是遗传缺陷 — 这只是概率规律。在足够大的人口中，从统计上说必然会有家庭出现很长的女孩连串。每次出生都是独立事件，“运气不好”的连串是随机性的自然结果。
