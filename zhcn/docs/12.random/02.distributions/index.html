第12.2章: 分布

English

概述

随机数引擎产生的是原始随机比特，但大多数应用需要落在特定区间内、或服从特定统计分布的随机值。C++ 的 <random> 库提供分布，把原始随机比特变换成所需的输出形式。

常见的分布包括：

  • ::std::uniform_int_distribution — 区间内均匀分布的整数
  • ::std::uniform_real_distribution — 均匀分布的浮点数
  • ::std::bernoulli_distribution — 给定概率的布尔值
  • ::std::normal_distribution — 正态（高斯）分布

uniform_int_distribution

在给定区间 [min, max] 内生成均匀分布的整数。 


#include <fast_io.h>
#include <random>

int main() {
    using namespace ::fast_io::io;

    ::std::mt19937_64 eng{12345u};  // Seeded for reproducibility

    // Generate integers in [1, 6] (like a die roll)
    ::std::uniform_int_distribution<int> die_dist(1, 6);

    println("Rolling a die 10 times:");
    for (::std::size_t i{}; i != 10; ++i) {
        print(die_dist(eng), " ");
    }
    print("\n");

    // Generate integers in [0, 99]
    ::std::uniform_int_distribution<int> percent_dist(0, 99);

    println("Random percentages:");
    for (::std::size_t i{}; i != 10; ++i) {
        print(percent_dist(eng), "% ");
    }
    print("\n");
}
绝不要用取模来生成区间！用 eng() % 100 得到 [0, 99] 内的值，会因鸽笼原理产生有偏分布。请始终使用 ::std::uniform_int_distribution，它用拒绝采样保证完美的均匀性。

bernoulli_distribution

生成布尔值（true 或 false），其中为 true 的概率由 p 指定。 


#include <fast_io.h>
#include <random>

int main() {
    using namespace ::fast_io::io;

    ::std::mt19937_64 eng{12345u};

    // Fair coin: 50% heads
    ::std::bernoulli_distribution fair_coin(0.5);

    println("Flipping a fair coin 10 times:");
    for (::std::size_t i{}; i != 10; ++i) {
        print(fair_coin(eng) ? "H" : "T", " ");
    }
    print("\n");

    // Biased coin: 70% heads
    ::std::bernoulli_distribution biased_coin(0.7);

    println("Flipping a biased coin (70% heads):");
    for (::std::size_t i{}; i != 10; ++i) {
        print(biased_coin(eng) ? "H" : "T", " ");
    }
    print("\n");

    // Rare event: 5% chance
    ::std::bernoulli_distribution rare_event(0.05);

    println("Simulating rare events (5% chance):");
    ::std::size_t count{};
    for (::std::size_t i{}; i != 100; ++i) {
        if (rare_event(eng)) {
            ++count;
        }
    }
    println("Occurred ", count, " times out of 100");
}

组合使用多个分布

对复杂场景，你可以把多个分布配合使用： 


#include <fast_io.h>
#include <random>

int main() {
    using namespace ::fast_io::io;

    ::std::mt19937_64 eng{12345u};

    // Distribution for number of items (1-5)
    ::std::uniform_int_distribution<int> count_dist(1, 5);

    // Distribution for item values (10-99)
    ::std::uniform_int_distribution<int> value_dist(10, 99);

    // Generate random number of random values
    int num_items = count_dist(eng);
    println("Generating ", num_items, " items:");

    for (int i{}; i != num_items; ++i) {
        println("  Item ", i + 1, ": ", value_dist(eng));
    }
}

分布的通用属性

所有分布都提供这些方法：

方法 说明
operator()(gen) 用给定的引擎生成下一个随机值
min() 返回该分布能产生的最小值
max() 返回该分布能产生的最大值
reset() 重置分布的内部状态
param() 取得或设置分布的参数

要点

  • 分布把引擎产生的原始随机比特变换成具有特定统计性质的值。
  • 区间内的整数请用 ::std::uniform_int_distribution — 绝不要用取模。
  • 给定概率的布尔值请用 ::std::bernoulli_distribution。
  • 分布可与任何引擎配合，包括 ::std::mt19937_64 和 ::fast_io::ibuf_white_hole_engine。
  • 需要密码学安全的随机性时，用 ibuf_white_hole_engine 而不是 mt19937_64。
