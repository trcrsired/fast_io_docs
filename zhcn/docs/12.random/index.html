第12章: random

English

概述

本章讲 fast_io 中的随机数生成。你将了解密码学安全的随机源、正确使用分布的重要性，以及如何使用安全引擎和可复现的伪随机引擎。

随机数生成对密码学、仿真、游戏以及许多其他应用都至关重要。fast_io 提供平台专用的安全随机源，并与它的 I/O 系统无缝集成。

要点

  • 随机性是安全属性，不只是分布。
  • 机密数据用 OS 熵源，可复现实验用带种子的 PRNG。
  • 不要用取模把分布压到某个范围；用分布 API。
  • 洗牌用现成算法，不要自己写有偏的版本。
