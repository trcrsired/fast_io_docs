第12.6章: 进阶分布

English

不止于均匀整数

C++ 的 <random> 库提供的分布远不止 uniform_int_distribution。它们全都能与 ibuf_white_hole_engine 无缝配合，因为后者满足 UniformRandomBitGenerator 要求。

一些常用分布包括：

  • ::std::uniform_real_distribution — 均匀分布的浮点值
  • ::std::normal_distribution — 正态（高斯）分布
  • ::std::bernoulli_distribution — 给定概率的布尔值
  • ::std::binomial_distribution — n 次试验中的成功次数
  • ::std::poisson_distribution — 固定区间内的事件数
  • ::std::exponential_distribution — 事件之间的时间

完整清单与详细文档见 cppreference — Random number generation。

示例：正态分布

正态（高斯）分布在统计、仿真和机器学习中常用。它产生的值围绕均值聚集，标准差由参数给定。 


#include <fast_io.h>
#include <fast_io_device.h>
#include <random>

int main() {
    using namespace ::fast_io::io;

    // Create secure random engine
    ::fast_io::ibuf_white_hole_engine eng;

    // Normal distribution: mean = 0.0, standard deviation = 1.0
    ::std::normal_distribution<double> dist(0.0, 1.0);

    // Generate 10 values from normal distribution
    println("Values from N(0, 1):");
    for (::std::size_t i{}; i != 10; ++i) {
        println(dist(eng));
    }

    // Different parameters: mean = 100.0, std dev = 15.0 (IQ scores)
    ::std::normal_distribution<double> iq_dist(100.0, 15.0);
    println("\nSimulated IQ scores:");
    for (::std::size_t i{}; i != 5; ++i) {
        println(iq_dist(eng));
    }
}

分布内部用 Box-Muller 或 Ziggurat 之类的算法，把均匀随机比特变换为正态分布的值，这些复杂工作都由它承担。

示例：伯努利分布

伯努利分布以给定概率产生布尔值（true 或 false）。它适合模拟抛硬币、是/否决策，或任何二值结果。 


#include <fast_io.h>
#include <fast_io_device.h>
#include <random>

int main() {
    using namespace ::fast_io::io;

    ::fast_io::ibuf_white_hole_engine eng;

    // Fair coin: 50% heads
    ::std::bernoulli_distribution fair_coin(0.5);

    // Biased coin: 70% heads
    ::std::bernoulli_distribution biased_coin(0.7);

    println("Fair coin flips (50% heads):");
    for (::std::size_t i{}; i != 10; ++i) {
        print(fair_coin(eng) ? "H" : "T", " ");
    }
    print("\n");

    println("Biased coin flips (70% heads):");
    for (::std::size_t i{}; i != 10; ++i) {
        print(biased_coin(eng) ? "H" : "T", " ");
    }
    print("\n");
}

正确使用分布

记住这些要点：

  • 绝不要用取模生成区间内的值，请始终使用合适的分布。
  • 为你的用例选择正确的分布 — 均匀、正态、伯努利等。
  • 使用 ibuf_white_hole_engine 获得安全、自动的播种。
  • 需要可复现结果时，用来自安全引擎的 ::std::seed_seq 为 ::std::mt19937_64 播种。

要点

  • C++ 提供的分布远不止 uniform_int_distribution，还包括 normal_distribution、bernoulli_distribution 以及许多其他分布。
  • 所有分布都能与 ibuf_white_hole_engine 无缝配合。
  • 为你的用例选择合适的分布 — 不要手动变换均匀值。
