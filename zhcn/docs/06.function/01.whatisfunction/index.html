第6.1章: 什么是函数？

English

概述

函数是执行特定任务的可复用代码块。 你在前面的章节中已经用过许多函数： main、::fast_io::io::println、 ::fast_io::io::scan，以及容器的构造函数。

函数让你能够：

  • 把代码组织成有意义的单元
  • 避免重复相同的逻辑
  • 给操作起名字
  • 把程序做什么与怎么做分开

在本章中，你将学到函数的基本结构、如何调用函数， 以及返回值如何工作。

1. 函数的基本语法

一个函数由四部分组成：

  • 返回类型
  • 名字
  • 参数列表
  • 用花括号括起来的函数体

int add(int a, int b) noexcept
{
    return a + b;
}

这个函数接受两个整数并返回它们的和。

调用函数


#include <fast_io.h>

int add(int a, int b) noexcept
{
    return a + b;
}

int main()
{
    using namespace ::fast_io::iomnp;

    int result = add(10, 20);
    println("Result = ", result);
}

表达式 add(10, 20) 调用该函数并产出一个值。

2. void 返回类型

不返回值的函数使用 void 类型。 


void greet() throws
{
    using namespace ::fast_io::iomnp;

    print("Hello!\n");
}

void 函数也以同样的方式调用： 


greet();

因为它不返回任何东西，你不能写： 


// int x = greet();   // ❌ error — greet() returns void

3. 形参与实参

函数定义中括号内的变量称为形参（parameter）。 当你调用函数时，传入的值称为实参（argument）。 


int square(int x) noexcept
{
    return x * x;
}

int y = square(5);   // 5 is the argument

形参在函数内部的行为就像局部变量。

4. return 语句

函数使用 return 语句返回值。 


double half(double x) noexcept
{
    return x / 2.0;
}

return 语句会立即结束函数。 


int test(int x) noexcept
{
    if(x < 0)
        return -1;   // function ends here

    return x * 2;    // otherwise return this
}

5. 为什么函数重要

函数是 C++ 中一切更高层抽象的基础。 它们让程序：

  • 更易读
  • 更易测试
  • 更易维护
  • 重复更少

后续章节会展示函数如何与引用、对象、 模板和 lambda 交互。现在，目标只是理解如何 定义并调用它们。

要点

  • 函数把代码组织成一个可复用的单元。
  • 函数有返回类型、名字、参数以及函数体。
  • void 表示“不返回任何东西”。
  • 形参是函数内部的局部变量。
  • 实参是调用函数时传入的值。
  • return 结束函数并产出一个值。
