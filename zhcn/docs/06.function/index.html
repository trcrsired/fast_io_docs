第6章: 函数

English

概述

本章介绍 C++ 中最重要的概念之一： 函数。函数让你能把代码组织成可复用、 有意义的单元。你到目前为止写的每个程序都已经在使用 函数，例如 main、::fast_io::io::println 以及容器的构造函数。

在本章中，你将学到：

  • 如何定义你自己的函数
  • 参数与返回值如何工作
  • 声明与定义的区别
  • 实参如何传递（按值、按引用、按 const 引用）
  • 函数重载如何工作
  • 默认实参如何工作
  • 如何编写 inline 与 constexpr 函数
  • 函数指针如何工作
  • lambda 表达式入门
  • 最后，在 第6.16章中，除 int main 之外的每个函数都要声明 noexcept 或 throws

本章的一个主要目标，是展示函数如何帮助你组织结构、 减少重复，并清晰地表达意图。函数是 C++ 中一切更高层 抽象的基础，包括类、模板和算法。
