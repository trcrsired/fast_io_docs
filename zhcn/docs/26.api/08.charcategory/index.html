第26.8章：char_category

English

1. char_category 是什么

fast_io::char_category 是编译期、与 locale 无关的字符分类层。 它回答 C locale 下 <cctype> 回答的问题，外加全角/半角 和少量路径/HTML 辅助，不需要 locale 对象；编译器能折叠时，运行时也没有函数调用。

每个谓词都是 constexpr 和 noexcept。 这一层接受 fast_io 使用的字符类型：char、wchar_t、 char8_t、char16_t 和 char32_t。

2. 谓词

谓词 何时为真
is_c_alnum(ch)字母或数字。
is_c_alpha(ch)字母。
is_c_blank(ch)空格或制表符。
is_c_cntrl(ch)控制字符。
is_c_digit(ch)十进制数字。
is_c_graph(ch)图形字符（字母数字或标点）。
is_c_lower(ch)小写字母。
is_c_print(ch)可打印字符，包括空格。
is_c_punct(ch)标点字符。
is_c_space(ch)空白：空格、制表、换行、回车、换页、垂直制表。
is_c_upper(ch)大写字母。
is_c_xdigit(ch)十六进制数字。
is_c_halfwidth(ch)半角字符。
is_c_fullwidth(ch)全角字符。
is_html_whitespace(ch)HTML 空白：空格、制表、LF、FF、CR。
is_dos_file_invalid_character(ch)DOS/Windows 文件名中非法的字符。
is_dos_path_invalid_prefix_character(ch)DOS 路径前缀开头非法的字符。头文件侧。
 

static_assert(::fast_io::char_category::is_c_digit('7'));
static_assert(!::fast_io::char_category::is_c_space('x'));

3. 大小写与宽度转换

转换函数是函数对象，不是宏，而且同样是 constexpr：

条目 效果
to_c_lower(ch) C locale 定义映射时，把大写字符转成小写。
to_c_upper(ch) 把小写字符转成大写。
to_c_halfwidth(ch) 把全角标点或形式转成已定义的半角形式。
ranges::to_c_lower(first, last[, proj]) 对迭代器/哨兵范围应用映射；返回最终迭代器。
ranges::to_c_upper(range[, proj]) 对范围应用映射；返回借用迭代器。
ranges::to_c_halfwidth(range[, proj]) 对范围应用半角转换。 

char c{'A'};
c = ::fast_io::char_category::to_c_lower(c);   // 'a'

::fast_io::string s{"Hello"};
::fast_io::char_category::ranges::to_c_upper(s);

range 版本接受投影，所以可以和成员访问器组合： 


::fast_io::char_category::ranges::to_c_lower(
    first, last, [](auto const &e) { return e.initial; });

4. char_category_traits

char_category_traits<family, negate> 把一个 family 变成可调用谓词。 它暴露 family、is_negate 和 char_is(ch)， 它的 operator() 调用 char_is。 这是可以存进表里或传给算法的形式。

char_category_family 含义
c_alnum字母数字。
c_alpha字母。
c_blank空格或制表。
c_cntrl控制。
c_digit数字。
c_fullwidth全角。
c_graph图形。
c_halfwidth半角。
c_lower小写。
c_print可打印。
c_punct标点。
c_space空白。
c_upper大写。
c_xdigit十六进制数字。
dos_file_invalid_characterDOS/Windows 文件名非法字符。
html_whitespaceHTML 空白。
 

using digit_pred = ::fast_io::char_category::char_category_traits<
    ::fast_io::char_category::char_category_family::c_digit, false>;

static_assert(digit_pred::char_is('5'));
static_assert(!digit_pred{}( 'x' ));

5. 模块与头文件边界

fast_io 模块导出：

  • char_category_family 和 char_category_traits；
  • to_c_lower、to_c_upper、to_c_halfwidth；
  • ranges::to_c_lower、ranges::to_c_upper 和 ranges::to_c_halfwidth 的 range 形式；
  • is_dos_file_invalid_character。

单独的 is_c_* 谓词目前属于头文件侧。 is_html_whitespace 和 is_dos_path_invalid_prefix_character 也是。 它们都可以通过 #include <fast_io.h> 使用； 如果使用模块，先包含需要的谓词头文件，直到导出列表扩展。

不是 locale。 char_category 不是 fast_io.i18n 层。它是 C locale 的分类和转换层。 答案需要随用户 locale 变化时，用 locale 模块。

要点

  • char_category 是编译期、与 locale 无关的字符分类。
  • 核心谓词对应 C <cctype> 家族，另加全角/半角、HTML 空白 和 DOS 文件名验证。
  • to_c_lower、to_c_upper 和 to_c_halfwidth 是 constexpr 函数对象；ranges:: 形式把它们应用到带可选投影的范围。
  • char_category_traits<family, negate> 是可调用、可存储的 family 形式。
  • 模块导出 traits、三个转换对象、它们的 range 形式以及 is_dos_file_invalid_character；单独的 is_c_* 谓词仍在头文件侧。
  • 这一层不是 locale；locale 相关格式化用 fast_io.i18n。
