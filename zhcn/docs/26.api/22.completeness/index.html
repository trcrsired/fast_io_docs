English

1. 这一页测什么

这是对模块导出列表的名字级审计，不表示每个提及都是完整规范。 当符号的最后一段名字出现在第26.1–26.21章任意位置时，标为 已记录；被导出但从未提及时，标为未记录。

审计覆盖 I/O、locale、crypto、TLS、freestanding、分配、hosted 和设备导出单元。 dsal 和 legacy 导出单元不在本次范围内； 它们的内容有自己的章节。没有进入模块导出列表的头文件侧 API 单独列在第5节。

当前结果：294 / 794 个导出名字被提及 （37.0%）。剩下 500 个就是明确的待办。 很多是逐字符别名或平台变体，不是独立概念。
