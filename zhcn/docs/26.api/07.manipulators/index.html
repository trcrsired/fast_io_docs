第26.7章：操纵器查找

English

1. 怎么读这一页

所有条目都在 ::fast_io::mnp，也就是 ::fast_io::manipulators 的别名。操纵器包住一个值，被下一次 print 或 scan 调用消费。它不是流状态。

标为 module 的条目在 fast_io 模块导出列表里； 标为 header 的条目存在于头文件，但模块还没有导出。 scan 侧的 *_get 家族整体属于头文件侧。

2. 整数进制

条目 签名 含义
base<N> base<N, showbase = false, full = false>(value) 2–36 进制，小写数字。
baseupper<N> baseupper<N, showbase = false, full = false>(value) 2–36 进制，适用时用大写数字。
bin bin<showbase = false, full = false>(value) 二进制。
oct oct<showbase = false, full = false>(value) 八进制。
dec dec<showbase = false, full = false>(value) 十进制。
hex hex<showbase = false, full = false>(value) 十六进制，小写。
hexupper hexupper<showbase = false, full = false>(value) 十六进制，大写。
hex0x hex0x<full = false>(value) 十六进制，带 0x 前缀。
hex0xupper hex0xupper<full = false>(value) 十六进制，带 0X 前缀。 

println(::fast_io::mnp::hex(255));        // ff
println(::fast_io::mnp::hex0x(255));      // 0xff
println(::fast_io::mnp::base<36>(35));    // z

3. 浮点格式

条目 签名 含义
decimal decimal(value)、decimal(value, precision) 最短十进制或固定精度。
general general(value)、general(value, precision) 通用浮点格式。
fixed fixed(value)、fixed(value, precision) 定点表示。
scientific scientific(value)、scientific(value, precision) 科学计数法。
hexfloat hexfloat(value)、hexfloat(value, precision) 十六进制浮点表示。
comma_* comma_decimal、comma_general、 comma_fixed、comma_scientific、 comma_hexfloat 同样的格式，带千位分组。 

println(::fast_io::mnp::fixed(3.14159, 2));   // 3.14
println(::fast_io::mnp::hexfloat(1.0));       // hexadecimal float

4. 布尔、宽度与对齐

条目 签名 含义
boolalpha boolalpha<uppercase = false>(bool) 用 true/false 而不是 1/0。
width width(placement, value, n)、 width(placement, value, n, fill) 填充到宽度 n；placement 是 scalar_placement::left、middle、right 或 internal。
left left(value, n)、left(value, n, fill) 在宽度 n 的字段里左对齐。
middle middle(value, n)、middle(value, n, fill) 在宽度 n 的字段里居中。
right right(value, n)、right(value, n, fill) 在宽度 n 的字段里右对齐。
internal internal(value, n)、internal(value, n, fill) 在符号/进制前缀和数字之间填充。 

println(::fast_io::mnp::boolalpha(true));
println(::fast_io::mnp::right(42, 8, '0'));   // 00000042

5. 指针与句柄视图

条目 签名 含义
pointervw pointervw<uppercase = false>(pointer) 打印指针值，不打印它指向的对象。
itervw itervw<uppercase = false>(iterator) 把连续迭代器打印成地址。头文件侧。
funcvw funcvw<uppercase = false>(function pointer) 打印函数指针。头文件侧。
fieldptrvw fieldptrvw<uppercase = false>(member object pointer) 打印成员对象指针。头文件侧。
methodvw methodvw<uppercase = false>(member function pointer) 打印成员函数指针。
addrvw addrvw<uppercase = false>(value) 打印地址形状的整数。
dfvw dfvw(value) 打印带 0x 和符号的默认形式地址。
handlevw handlevw<uppercase = false>(handle) 打印 OS 句柄；整数句柄用十进制。
bitfieldvw bitfieldvw(value) 把 bit-field 或字节值按整数视图打印。

指针作为数据时要说清楚。直接传 char const * 打印的是指针值，不是字符串； 文本用 os_c_str 或 strvw。

6. 字符串与范围视图

条目 签名 含义
os_c_str os_c_str(ptr, n)、os_c_str(range) 已知大小的 OS 原生字符串；在 NUL 处停止。
os_c_str_carr os_c_str_carr(array) 同上，用于字符数组。
os_c_str_null_terminated os_c_str_null_terminated(ptr, n) 已知容量的 NUL 结尾字符串。
os_c_str_null_terminated_carr os_c_str_null_terminated_carr(array) 同上，用于字符数组。
os_c_str_or_nullptr os_c_str_or_nullptr(ptr) 打印字符串或空表示。
os_c_str_with_known_size os_c_str_with_known_size(ptr, n) 带显式字节/字符数的字符串。
strvw strvw(first, last)、strvw(range) 非拥有字符范围，作为 scatter。
rgvw rgvw(range, separator) 在元素之间插入分隔符打印范围。 

::fast_io::string_view sv{"hello"};
println(::fast_io::mnp::strvw(sv));
println(::fast_io::mnp::rgvw(::fast_io::array<int, 3>{1, 2, 3}, ", "));

7. 编码、二进制、网络与错误

条目 签名 含义
code_cvt code_cvt<src, dst>(value) 输出时在编码方案之间转换。
code_cvt_os_c_str code_cvt_os_c_str<src, dst>(ptr[, n]) 对 C 字符串做编码转换。
leb128_put leb128_put(value) 写一个 LEB128 整数。
leb128_get leb128_get(ref) 把 LEB128 整数读进 ref。
ip_generic ip_generic(ip) 带 flags 打印 IPv4/IPv6/地址/端口类型。
ip_scan_generic ip_scan_generic(ip&) 带 flags 扫描进 IP 类型。
cur_src_loc cur_src_loc(source_location = current()) 打印文件、行、列和函数。
name、message、name_message 错误查询包装 打印 herbception 错误的名称、消息或两者。
posix_equivalent_* 错误查询包装 POSIX 等价的名称/消息形式。
lc_dump lc_dump(locale) 把整个 locale 打印成文本。
lf、crlf、cr lf()、crlf()、cr() 扫描用的行跳过器。

ip_flags、ip_scan_default_flags、scalar_flags、 scalar_manip_t、ip_manip_t 以及 placement/format 枚举 是这些值背后的类型。它们和导出列表一起记录在 第26.1章。

8. scan 侧操纵器

这些是 scan 使用的头文件侧对应物。模块目前还没有导出它们。

条目 签名 含义
ch_get ch_get(ref) 读一个字符，不把它当数字。
base_get<N> base_get<N, noskipws, skipzero, prefix>(ref) 按 2–36 进制读整数。
bin_get、oct_get、dec_get、hex_get 与 base_get 相同的 flag 形状 特定进制的整数读取。
addrvw_get addrvw_get(ref) 读取地址形状的十六进制整数。
strlike_get strlike_get(ref) 把空白分隔的 token 读进字符串类目标。
strlike_line_get strlike_line_get(ref) 把一行读进字符串类目标。
strlike_whole_get strlike_whole_get(ref) 读取剩余的全部输入。 

int x{};
::fast_io::io::scan(in, ::fast_io::mnp::hex_get(x));

::fast_io::string line;
::fast_io::io::scan(in, ::fast_io::mnp::strlike_line_get(line));

要点

  • 操纵器是单参数包装，不是持久流状态。
  • 整数进制、浮点格式、宽度、指针和字符串视图是主要输出家族。
  • boolalpha、ip_generic、leb128_put、 code_cvt 和错误查询包装覆盖其余输出领域。
  • scan 侧 *_get 操纵器与输出操纵器是分开的。
  • 模块导出和头文件侧条目都有标记；不要假定头文件辅助在模块契约里。
  • 裸 char const * 打印为指针；文本要包 os_c_str 或 strvw。
