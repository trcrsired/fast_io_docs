第26.16章：时间

English

1. 两种时间类型

类型 内容 用途
posix_timespec64 tv_sec（Unix 纪元以来的有符号 64 位秒）和 tv_nsec（32 位纳秒）。 机器和系统调用表示。
iso8601_timestamp year、month、day、hours、 minutes、seconds、nanoseconds 和 timezone。 人类/日历表示。

posix_timespec64 支持算术：加法、减法、取负和除以整数。 操作会规范化纳秒，所以 1s + 500ms 是一个合法的 timespec， tv_nsec == 500000000，不是原始字段相加。

2. 时钟查询

posix_clock_gettime(id) 返回 posix_timespec64。 posix_clock_getres(id) 返回时钟分辨率。两者都是 hosted API； freestanding 目标自己提供时钟。

posix_clock_id 含义
realtime自纪元以来的墙上时钟时间。
realtime_coarse较低分辨率的实时时钟。
realtime_alarm闹钟时钟。
tai国际原子时，平台支持时可用。
monotonic单调时钟，不受墙上时钟调整影响。
monotonic_coarse、monotonic_raw、monotonic_raw_approx粗/原始单调变体。
boottime、boottime_alarm自启动以来的时间及其闹钟。
process_cputime_id、thread_cputime_id进程或线程的 CPU 时间。
 

auto const now{::fast_io::posix_clock_gettime(::fast_io::posix_clock_id::realtime)};

不是每个平台都实现每个时钟。不支持的时钟通过 herbception 通道失败， 而不是返回零时间戳。

3. UTC 与本地时间转换

条目 含义 模块
utc(timespec) 把 Unix 时间戳转成 UTC 的 ISO 8601 日历值。 fast_io
local(timespec, dstadj = posix_daylight()) 转成本地时间；可能查询平台时区。 fast_io
to_posix_timespec64(iso) 把 ISO 8601 值转回 Unix 时间戳。 fast_io
to_posix_timespec64_ftu64 从定点 64 位时间戳转换。 fast_io
posix_timespec64_to_ftu64 转成定点 64 位时间戳。 fast_io
posix_daylight() 本地时间当前是否使用夏令时。 头文件侧
timezone_name(dst) 平台时区缩写。 头文件侧 

auto const t{::fast_io::posix_clock_gettime(::fast_io::posix_clock_id::realtime)};
auto const iso{::fast_io::utc(t)};
::fast_io::io::println(iso);

utc 是 constexpr 且纯的；local 不是， 因为它查询平台时区和夏令时状态。线格式用 utc， 只在显示时用 local。

4. 打印与扫描

iso8601_timestamp 可以直接打印和扫描。打印形式是 ISO 8601 日历字符串； 扫描器接受同样的形式。 


::fast_io::iso8601_timestamp ts;
::fast_io::io::scan(in, ts);
::fast_io::io::println(ts);

需要指定小数精度的 Unix 时间戳时，用 mnp::fixed 包一个 posix_timespec64： 


::fast_io::io::println(::fast_io::mnp::fixed(t, 3));   // seconds.milliseconds
::fast_io::io::println(::fast_io::mnp::comma_fixed(t, 6));

精度是小数部分的十进制位数。comma_fixed 给整数部分加数字分组。

包含 chrono 单位头文件时，std::chrono::duration 值可打印。 支持的周期是纳秒、微秒、毫秒、秒、分、小时、天、周、月、年； 输出带单位后缀。

5. 时区规则

  • utc 永远不依赖进程时区。
  • local 向平台查询偏移和 DST 状态；已经解析过时显式传 dstadj。
  • timezone_name 是显示元数据；不要把它当稳定标识符解析。
  • 带非零 timezone 字段的时间戳仍然是绝对时刻加偏移； 用 to_posix_timespec64 转回时会规范化。

6. 模块与头文件边界

fast_io 模块导出 posix_timespec64、 iso8601_timestamp、utc、local、 to_posix_timespec64、to_posix_timespec64_ftu64 和 posix_timespec64_to_ftu64。hosted 单元增加 posix_clock_id、posix_clock_gettime 和 posix_clock_getres。posix_daylight、 timezone_name 和 chrono duration 打印钩子在头文件侧。

要点

  • posix_timespec64 是机器时间戳；iso8601_timestamp 是日历值。
  • posix_clock_gettime 返回规范化 timespec；不支持的时钟会失败。
  • utc 是纯的、constexpr；local 查询平台时区。
  • ISO 8601 值可以直接打印和扫描。
  • mnp::fixed 和 comma_fixed 按选定小数精度打印 Unix 时间戳。
  • 包含 chrono 单位头文件时，chrono duration 带单位后缀打印。
  • 线格式用 UTC，本地时间只用于显示。
