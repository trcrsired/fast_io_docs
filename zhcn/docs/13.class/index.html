第13章: 类

English

概述

到目前为止你写的一切，都是由别人定义的类型构成的：::std::int_least32_t、::fast_io::string、::fast_io::str_btree_map。类就是你为自己定义类型的方式。

类把数据与作用于这些数据的函数放进同一个东西里，给它一个名字，然后决定程序的其余部分可以对它做什么。最后这一点正是整章的重点：类不是一堆字段的袋子，而是一小组承诺，实现被藏在承诺之后。

本章跟着一个类型从初稿走到成品设计：开头是 point，结尾是 account。每个子章加一个想法，代码随之生长。

类是一个承诺，不是一个容器。如果一个类承诺“余额永远不为负”，那么类里的每个函数都必须让这个承诺成立，而调用者因此可以停止检查。封装就是让这个承诺可信的手段：数据是私有的，所以唯一能破坏承诺的代码，就是你在那个类里写的代码。

本章使用的约定

  • 不用 int。整数类型写作 ::std::int_least32_t（金额用 ::std::int_least64_t），大小写作 ::std::size_t。int 的宽度语言并不保证，而这些类型的宽度是有保证的。用能表达你意图的类型，而不是打字最短的那个。
  • 私有数据成员以 _ 结尾（balance_），公有数据成员不以它结尾（x）。一眼就能看出这个名字住在墙的哪一侧。
  • 每个成员函数都是 noexcept 或 throws，与自由函数完全一样（第6.16章）。可能失败的成员函数声明为 throws，调用者用 try { } catch throws (::std::error e) { } 处理（第3.16章）。
  • 每个示例都是完整的程序，它下面的输出就是你运行它得到的输出。
