第13.2章: 成员函数

English

1. 一个对象，一次一个操作

成员函数是写在类内部、把它被调用的那个对象作为一个看不见的额外实参接收、并用点语法调用的函数： 


point p{3, 4};
println(p.sum());       // call sum() with p as the object
p.shift_by(10);          // call shift_by(10) with p as the object

关于它的其他一切都与你在第6章学到的完全一样：参数、返回类型、重载、默认实参，以及 noexcept / throws 规格。类内部并没有另一门更简单的语言。成员函数只是一个有“主体”的函数。

2. 类内声明，类外定义

对一行函数来说，把函数体写在类里就可以了。对更长的函数，通常的风格是在类内部声明，在类外部定义，并加上类名和 :: 前缀： 


class point
{
public:
	::std::int_least32_t sum() const noexcept;   // declaration
};

::std::int_least32_t point::sum() const noexcept   // definition
{
	return x + y;
}

point::sum 是函数的限定名。那个 point:: 不是装饰：正是它让这个是属于 point 的 sum，而不是别的类里某个其他的 sum。在它自己的函数体内，以及在这个类的其他任何成员里，成员都在作用域内，不需要任何前缀：return x + y; 不需要 this->。

完整程序，包含两个重载、一个默认实参，以及一个调用其他成员函数的成员函数： 


#include <fast_io.h>
#include <cstdint>
using namespace ::fast_io::io;

class point
{
public:
	::std::int_least32_t x{};
	::std::int_least32_t y{};

	// Declared here, defined outside the class.
	::std::int_least32_t sum() const noexcept;

	// Two overloads, both defined outside.
	void shift_by(::std::int_least32_t dx) noexcept;
	void shift_by(::std::int_least32_t dx, ::std::int_least32_t dy) noexcept;

	// A method that calls other methods.
	::std::int_least32_t doubled_sum() const noexcept;
};

::std::int_least32_t point::sum() const noexcept
{
	return x + y;
}

void point::shift_by(::std::int_least32_t dx) noexcept
{
	shift_by(dx, 0); // calls the two-argument overload
}

void point::shift_by(::std::int_least32_t dx, ::std::int_least32_t dy) noexcept
{
	x += dx;
	y += dy;
}

::std::int_least32_t point::doubled_sum() const noexcept
{
	return 2 * sum();
}

class counter
{
public:
	::std::int_least32_t value{};

	// Default arguments work exactly as they do for free functions.
	void add(::std::int_least32_t n = 1) noexcept
	{
		value += n;
	}
	void reset() noexcept
	{
		value = 0;
	}
};

int main()
{
	point p{3, 4};
	println("sum         = ", p.sum());
	println("doubled_sum = ", p.doubled_sum());

	p.shift_by(10);
	println("after shift_by(10):   ", p.x, ", ", p.y);

	p.shift_by(1, 2);
	println("after shift_by(1, 2): ", p.x, ", ", p.y);

	counter c{};
	c.add();
	c.add(10);
	println("counter = ", c.value);
	c.reset();
	println("counter = ", c.value);
}


sum         = 7
doubled_sum = 14
after shift_by(10):   13, 4
after shift_by(1, 2): 14, 6
counter = 11
counter = 0

从中可以得出三点：

  • 重载的行为与自由函数完全相同（看那两个 shift_by）。编译器根据你传入的实参来挑选，在它已经知道的那个对象之外再加上这些。
  • 默认实参同样有效（add(n = 1)）。一如既往，默认值写在调用者看得见的那份声明上。
  • 成员函数按名字互相调用（shift_by(dx, 0)、sum()）。不需要写出对象，因为只有一个合理的对象：调用者手里已经有的那个。

3. 成员函数要声明为 noexcept 或 throws

成员函数就是函数，所以它在本教程中受到与其他函数同样的对待：它要么是 noexcept（不会失败），要么是 throws（可以把失败报告给调用者）（第6.16章）。打印就是 I/O，而 I/O 可能失败，所以会打印的成员函数是 throws： 


class point
{
public:
	void print() const throws          // correct: it does I/O
	{
		println("(", x, ", ", y, ")");
	}
};

如果你把它标成 noexcept，编译器会拦在 println 那一行，并准确告诉你原因： 


error: call to a 'throws' or 'return_failure{E}' function must be handled by an
       enclosing 'try { } catch throws', or the calling function needs a
       herbceptions specification so the error can propagate

措辞与自由函数完全一样，因为规则就是同一条规则。这正是有用的地方：语言里只有一个错误处理概念，而且当你走过类的定义时它不会改变形状。

定义该放在哪里？如果一个类被多个 .cc 文件使用，类定义要放在头文件里，而每个定义在类外部的成员函数都必须是 inline（或者只在一个 .cc 文件里定义一次）。定义在类体内部的成员函数自动是 inline。本教程每个示例都放在一个文件里，所以没什么需要写成 inline。

4. const 登场了

示例中大多数声明以 const 结尾：sum() const、doubled_sum() const。这个词是一个承诺，表示该成员函数不会改动对象，而且它不是可选的装饰 — 它决定了你能否在 const 对象上调用这个函数。它有自己的子章，因为它是本章最重要的习惯：第13.3章。
