第13.1章: 什么是类：数据与属于它的函数

English

1. 数据，以及作用于它的函数

下面是一个点，写法和你目前写过的一切一样：一个有两个成员的 struct，以及一个接受它的自由函数： 


struct point_data
{
	::std::int_least32_t x;
	::std::int_least32_t y;
};

::std::int_least32_t sum_of(point_data const &p) noexcept
{
	return p.x + p.y;
}

这样能工作，但它有一个与风格无关的真实弱点：没有任何东西把两者联系起来。那个函数必须把类型名写两遍，还必须写在类型可见的地方。编译器里没有任何东西知道 sum_of 就是“那个”求点之和的函数，因此没有途径去发现一个点支持哪些操作 — 你只能 grep 一下，然后祈祷。

现在把同一件事写成类。两个整数和两个操作生活在同一个类型里，操作则用你已经在 ::fast_io::string 成员上用过的点语法调用： 


#include <fast_io.h>
#include <cstdint>
using namespace ::fast_io::io;

// The old way: the data and the functions that work on it are separate.
struct point_data
{
	::std::int_least32_t x;
	::std::int_least32_t y;
};

::std::int_least32_t sum_of(point_data const &p) noexcept
{
	return p.x + p.y;
}

// A class: the data and the operations that belong to it, together, in one type.
class point
{
public:
	::std::int_least32_t x{};
	::std::int_least32_t y{};

	::std::int_least32_t sum() const noexcept
	{
		return x + y;
	}
	::std::int_least32_t product() const noexcept
	{
		return x * y;
	}
};

int main()
{
	point a{3, 4};
	point b{-2, 5};

	println("a.sum()     = ", a.sum());
	println("a.product() = ", a.product());
	println("b.sum()     = ", b.sum());
	println("b.product() = ", b.product());

	point_data d{3, 4};
	println("sum_of(d)   = ", sum_of(d));
}


a.sum()     = 7
a.product() = 12
b.sum()     = 3
b.product() = -10
sum_of(d)   = 7

语言并没有增加任何东西。sum() 是一个普通函数，只不过声明在类内部；a.sum() 是一次普通的函数调用，只不过它同时说明了在哪个对象上执行。全部机制就是这样：成员函数就是一个多了一个看不见实参的函数 — 那个实参就是对象（第13.7章）。

术语只讲一遍。类里的变量叫数据成员（也叫字段、属性）。类里的函数叫成员函数（也叫方法）。类类型的变量称为该类的对象（或实例）。C++ 程序员把这些词混用，所以本教程在需要区分时统一说“数据成员”和“成员函数”。

2. 对象就是普通的值

这一点会让来自“对象很特殊”的语言的人惊讶：这里的 point 不是引用、不是句柄、也不是指针。它就是那两个整数，存放在你放它的地方，没有任何额外分配。因此你学到的一切关于值的知识继续有效：

  • point a{3, 4}; — 对象活在栈上，8 字节，堆上什么都没有。
  • point ps[3]{{1, 2}, {3, 4}, {5, 6}}; — 它们的数组就只是一个数组。
  • point const &p — 把点传给函数传的是它的地址，而 const 表示这个函数不会改它。
  • for (auto const &p : ps) — 对点的数组做 range-for，就像对任何东西的数组做 range-for 一样。 

#include <fast_io.h>
#include <cstdint>
#include <cstddef>
using namespace ::fast_io::io;

class point
{
public:
	::std::int_least32_t x{};
	::std::int_least32_t y{};

	::std::int_least32_t sum() const noexcept
	{
		return x + y;
	}
};

::std::int_least32_t total(point const *ps, ::std::size_t n) noexcept
{
	::std::int_least32_t sum{};
	for (::std::size_t i{}; i != n; ++i)
	{
		sum += ps[i].sum();
	}
	return sum;
}

int main()
{
	point ps[3]{{1, 2}, {3, 4}, {5, 6}};
	for (auto const &p : ps)
	{
		println(p.x, " + ", p.y, " = ", p.sum());
	}
	println("total = ", total(ps, 3));
}


1 + 2 = 3
3 + 4 = 7
5 + 6 = 11
total = 21

注意 total 是一个自由函数，它对点的了解不超出类展示给它的东西：ps[i].sum()。这正是由类构建的程序通常的形状 — 小的类型对自己知道很多，自由函数把它们组合起来。

3. 类到底给你带来了什么

用结构体加自由函数 用类加成员函数
操作散落各处；要找它们得搜索整个程序。 操作列在类型内部。它的定义就是它的文档。
任何地方的任何代码都能写 p.x = -999，破坏数据本来该有的含义。 由你决定谁可以碰 x（第13.4章）。
新的不变量（“坐标永远不为负”）必须在每个调用点检查一遍。 不变量在类内部检查一次就够（第13.5章）。
改表示方式意味着要改每一个拆开过这个结构体的函数。 只有类本身要改，接口保持不变（第13.5章）。
没有任何东西强制对象以合理状态开始。 构造函数强制它（第13.6章）。
在这个子章里数据成员仍然是公有的。这是刻意的：point a{3, 4}; 之所以能这样写，是因为这个类没有构造函数、所有成员都是公有的，于是花括号按声明顺序初始化成员。第13.4章会把门关上，第13.6章给出取代这套语法的构造函数。从那以后，创建对象的方式是构造函数调用，而不是一个要你手动保持同步的花括号列表。
