第11.10.4章: fast_io 中的协议支持

English

socket 层支持什么

与主要聚焦 TCP 和 UDP 的 Boost.Asio 不同，fast_io 的 socket API 通过操作系统的原生 socket 接口支持广泛的协议：

  • TCP — 可靠的、面向连接的流（最常用）
  • UDP — 不可靠的、无连接的数据报（快、开销低）
  • Unix 域套接字 — 本地进程间通信（POSIX）
  • 蓝牙 — 蓝牙 socket（在操作系统支持时）
  • 原始套接字 — 直接访问 IP/ICMP 等（需要 root/管理员权限）
  • 其他协议 — 操作系统 socket API 支持的任何协议

关键差别在于：fast_io 直接包装操作系统的 socket 接口，因此你能用到操作系统支持的一切。你不会被限制在一份硬编码的协议清单上。

对 TCP 与 UDP，fast_io 提供 tcp_connect()、tcp_listen() 以及 DNS 解析这样的便捷函数。对其他协议，你可以直接从操作系统的 socket 句柄构造 socket 文件。

要点

  • socket API 只是操作系统 socket 接口的薄包装；协议清单来自操作系统，不是 fast_io 自己维护的列表。
  • TCP 和 UDP 有便捷函数；其他协议直接从原生 socket 句柄构造。
  • 协议支持是平台属性，依赖蓝牙、原始套接字或 Unix 域套接字之前先确认目标系统。
  • 原始套接字和部分协议族需要提升权限。
