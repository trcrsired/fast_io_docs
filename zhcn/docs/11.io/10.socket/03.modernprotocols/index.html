QUIC（Quick UDP Internet Connections）

QUIC 是 Google 开发、由 IETF 标准化的传输层协议。它运行在 UDP 之上，提供：

  • 更低的延迟 — 0-RTT 连接建立（对比 TCP 的三次握手）
  • 没有队头阻塞 — 某个流中的丢包不会阻塞其他流
  • 连接迁移 — 可以在 Wi-Fi 与蜂窝网络之间切换而不中断
  • 内建加密 — TLS 1.3 集成在传输层
  • 更好的拥塞控制 — 采用现代算法，比（位于内核中的）TCP 更容易演进

HTTP/3 用 QUIC 作为传输层。QUIC 也被 WebTransport 等其他协议使用。

WebSocket 与服务端发送事件

  • WebSocket — 在单条 TCP 连接上的全双工通信。先以一个 HTTP 升级请求开始，之后双方都可以随时发送数据。用于聊天、实时更新、游戏。
  • 服务端发送事件（SSE） — 服务器通过 HTTP 向客户端推送更新。比 WebSocket 简单，但只能服务端到客户端。用于新闻流、通知。
