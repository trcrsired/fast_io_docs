第11.3.1章: 操纵器参考

English

本页是 fast_io 提供的所有操纵器的完整参考。操纵器位于 ::fast_io::manipulators 命名空间，简写为 ::fast_io::mnp；使用它们需要 #include <fast_io.h>。下面每个示例都假定已经 using namespace ::fast_io::iomnp;，这样 print、println、scan 都能按名字使用。

下面每一节按用途对操纵器分组。表格列出操纵器签名、简短说明，以及一个显示调用的例子。

1. 整数进制操纵器

控制打印或扫描整数时使用的数制。base<N> 家族接受任意 2 到 36 之间的进制。

操纵器 说明 示例
::fast_io::mnp::base<N>(t) 以小写数字在 N 进制（2 ≤ N ≤ 36）下打印或扫描 t。 ::fast_io::mnp::base<36>(value)
::fast_io::mnp::baseupper<N>(t) 与 base<N> 类似，但对 ≥ 10 的数字值使用大写字母 A–Z。 ::fast_io::mnp::baseupper<16>(value)
::fast_io::mnp::hex(t) 以小写十六进制（16 进制）打印或扫描 t。 ::fast_io::mnp::hex(0xDEAD)
::fast_io::mnp::hexupper(t) 以大写十六进制（16 进制，数字 A–F）打印或扫描 t。 ::fast_io::mnp::hexupper(0xBEEF)
::fast_io::mnp::hex0x(t) 与 hex 类似，但在输出前加 0x 前缀。 ::fast_io::mnp::hex0x(42) → 0x2a
::fast_io::mnp::hex0xupper(t) 与 hexupper 类似，但在输出前加 0x 前缀。 ::fast_io::mnp::hex0xupper(42) → 0x2A
::fast_io::mnp::dec(t) 以十进制（10 进制）打印或扫描 t。这是整数的默认做法。 ::fast_io::mnp::dec(1234)
::fast_io::mnp::oct(t) 以八进制（8 进制）打印或扫描 t。 ::fast_io::mnp::oct(0777)
::fast_io::mnp::bin(t) 以二进制（2 进制）打印或扫描 t。 ::fast_io::mnp::bin(0b1010)
::fast_io::mnp::uhexfull(t) 把 t 打印为零填充、全宽的小写十六进制值（显示所有半字节）。 ::fast_io::mnp::uhexfull(std::uint32_t{0xFF}) → 000000ff
::fast_io::mnp::uhexupperfull(t) 与 uhexfull 类似，但使用大写十六进制数字 A–F。 ::fast_io::mnp::uhexupperfull(std::uint32_t{0xFF}) → 000000FF

2. 指针 / 地址操纵器

以平台合适的十六进制形式格式化指针、地址与可调用引用。

操纵器 说明 示例
::fast_io::mnp::addrvw(t) 以全宽、带 0x 前缀的十六进制打印通用地址（指针、句柄等）。 ::fast_io::mnp::addrvw(ptr)
::fast_io::mnp::pointervw(t) 以十六进制地址形式打印普通对象指针。 ::fast_io::mnp::pointervw(&obj)
::fast_io::mnp::itervw(t) 以十六进制打印迭代器底层的地址。 ::fast_io::mnp::itervw(vec.begin())
::fast_io::mnp::funcvw(t) 以十六进制地址形式打印函数指针。 ::fast_io::mnp::funcvw(&main)
::fast_io::mnp::fieldptrvw(t) 以十六进制形式打印数据成员指针。 ::fast_io::mnp::fieldptrvw(&MyStruct::field)
::fast_io::mnp::methodvw(t) 以十六进制形式打印成员函数指针。 ::fast_io::mnp::methodvw(&MyClass::doWork)
::fast_io::mnp::handlevw(t) 以十六进制形式打印操作系统句柄或文件描述符值。 ::fast_io::mnp::handlevw(posix_file.fd())

3. 布尔操纵器

控制 bool 值如何打印。默认情况下，布尔值打印为 1 或 0。

操纵器 说明 示例
::fast_io::mnp::boolalpha(b) 把 b 打印为 "true" 或 "false"（小写）。 ::fast_io::mnp::boolalpha(flag) → true
::fast_io::mnp::boolalpha<true>(b) 把 b 打印为 "TRUE" 或 "FALSE"（大写）。 ::fast_io::mnp::boolalpha<true>(flag) → TRUE

4. 浮点操纵器

选择打印浮点值时使用的记法。可选的第二个实参 n 指定小数位数。

操纵器 说明 示例
::fast_io::mnp::hexfloat(t)
::fast_io::mnp::hexfloat(t, n) 		以十六进制浮点记法打印 t（例如 0x1.921fb6p+2）。 ::fast_io::mnp::hexfloat(3.14)
::fast_io::mnp::decimal(t)
::fast_io::mnp::decimal(t, n) 		以普通十进制浮点记法打印 t，保留 n 位小数。 ::fast_io::mnp::decimal(3.14, 4) → 3.1400
::fast_io::mnp::general(t)
::fast_io::mnp::general(t, n) 		用 decimal 与 scientific 中较短的那种打印 t，保留 n 位有效数字。 ::fast_io::mnp::general(123456.0, 3)
::fast_io::mnp::fixed(t)
::fast_io::mnp::fixed(t, n) 		以定点记法打印 t，小数点后保留 n 位。 ::fast_io::mnp::fixed(3.14, 2) → 3.14
::fast_io::mnp::scientific(t)
::fast_io::mnp::scientific(t, n) 		以科学（指数）记法打印 t，保留 n 位小数。 ::fast_io::mnp::scientific(3.14, 2) → 3.14e+00
::fast_io::mnp::comma_hexfloat(t)
::fast_io::mnp::comma_hexfloat(t, n) 		与 hexfloat 类似，在整数部分插入千位分隔符。 ::fast_io::mnp::comma_hexfloat(4096.0)
::fast_io::mnp::comma_decimal(t)
::fast_io::mnp::comma_decimal(t, n) 		与 decimal 类似，插入千位分隔符。 ::fast_io::mnp::comma_decimal(1234567.89, 2)
::fast_io::mnp::comma_general(t)
::fast_io::mnp::comma_general(t, n) 		与 general 类似，插入千位分隔符。 ::fast_io::mnp::comma_general(9876543.21)
::fast_io::mnp::comma_fixed(t)
::fast_io::mnp::comma_fixed(t, n) 		与 fixed 类似，插入千位分隔符。 ::fast_io::mnp::comma_fixed(12345.678, 2)
::fast_io::mnp::comma_scientific(t)
::fast_io::mnp::comma_scientific(t, n) 		与 scientific 类似，插入千位分隔符。 ::fast_io::mnp::comma_scientific(1234567.89, 2)

5. 宽度 / 对齐操纵器

把 t 的输出补齐到至少 n 列宽。可选的第三个实参是填充字符。

操纵器 说明 示例
::fast_io::mnp::left(t, n) 在宽度为 n 的字段内左对齐 t，用空格填充。 ::fast_io::mnp::left("hi", 10) → "hi        "
::fast_io::mnp::left(t, n, ch) 在宽度为 n 的字段内左对齐 t，用 ch 填充。 ::fast_io::mnp::left("hi", 10, '.') → "hi........"
::fast_io::mnp::right(t, n) 在宽度为 n 的字段内右对齐 t，用空格填充。 ::fast_io::mnp::right("hi", 10) → "        hi"
::fast_io::mnp::right(t, n, ch) 在宽度为 n 的字段内右对齐 t，用 ch 填充。 ::fast_io::mnp::right("hi", 10, '_') → "________hi"
::fast_io::mnp::middle(t, n) 在宽度为 n 的字段内居中 t，用空格填充。 ::fast_io::mnp::middle("hi", 10) → "    hi    "
::fast_io::mnp::middle(t, n, ch) 在宽度为 n 的字段内居中 t，用 ch 填充。 ::fast_io::mnp::middle("hi", 10, '=') → "====hi===="
::fast_io::mnp::internal(t, n) 在宽度为 n 的字段内，把填充放在符号或进制前缀之后、数字之前，用空格填充。 ::fast_io::mnp::internal(-42, 8) → "-     42"
::fast_io::mnp::internal(t, n, ch) 与 internal 类似，但用 ch 作为填充字符。 ::fast_io::mnp::internal(-42, 8, '0') → "-0000042"

6. 条件操纵器

在运行期根据一个布尔谓词在两种输出之间选择。谓词为真时用第一种，否则用第二种。

操纵器 说明 示例
::fast_io::mnp::cond(pred, t1, t2) pred 为 true 时打印 t1，否则打印 t2。 ::fast_io::mnp::cond(ok, "pass", "fail")
::fast_io::mnp::cond(pred, t1) pred 为 true 时打印 t1，否则什么都不打印。 ::fast_io::mnp::cond(showDetail, extra)

7. 百分比操纵器

把比例 num / deno 格式化成人类可读的百分比。percentage_* 家族还可与逗号小数分隔符组合。

操纵器 说明 示例
::fast_io::mnp::percentage_conventional(num, deno) 以常规的 10 进制百分比打印 num/deno（例如 75%）。 ::fast_io::mnp::percentage_conventional(3, 4) → 75%
::fast_io::mnp::base_percentage_conventional<N>(num, deno) 以 N 进制打印 num/deno 的百分比。 ::fast_io::mnp::base_percentage_conventional<16>(0xFF, 0x100)

8. 序数操纵器

追加英文序数后缀（st、nd、rd 或 th）。

操纵器 说明 示例
::fast_io::mnp::ordinal(t) 打印整数 t 并附上英文序数后缀：1st、2nd、3rd、4th。 ::fast_io::mnp::ordinal(42) → 42nd

9. Range 视图操纵器

打印 range 的每个元素，用给定分隔符隔开。这取代了手写循环的需要。

操纵器 说明 示例
::fast_io::mnp::rgvw(r, sep) 打印 range r 的每个元素，在相邻元素之间插入字符串 sep。 ::fast_io::mnp::rgvw(vec, ",") → 1,2,3

10. 字符 / 字符串操纵器

用于打印单个字符和 C 风格字符串指针的底层辅助工具，不依赖任何分配。

操纵器 说明 示例
::fast_io::mnp::chvw(ch) 打印单个字符 ch。 ::fast_io::mnp::chvw('A')
::fast_io::mnp::small_scatter(s) 打印一小段字符串字面量或编译期已知的字符串 s，不发生堆分配。 ::fast_io::mnp::small_scatter("hello")
::fast_io::mnp::os_c_str(ch, n) 从 C 字符串指针 ch 打印 n 个字符，不要求以空字符结尾。 ::fast_io::mnp::os_c_str(buf, len)
::fast_io::mnp::os_c_str_null_terminated(ch, n) 从以空字符结尾的 C 字符串 ch 打印至多 n 个字符，遇到空字符时停止。 ::fast_io::mnp::os_c_str_null_terminated(cstr, maxLen)

11. 十六进制编码操纵器

把一段连续的字节编码成十六进制字符串。这些操纵器既接受迭代器对，也接受 range。

操纵器 说明 示例
::fast_io::mnp::hex_encode(first, last) 把 [first, last) 中的字节编码成小写十六进制串。 ::fast_io::mnp::hex_encode(buf.data(), buf.data() + buf.size())
::fast_io::mnp::hex_encode_upper(first, last) 把 [first, last) 中的字节编码成大写十六进制串。 ::fast_io::mnp::hex_encode_upper(buf.data(), buf.data() + buf.size())
::fast_io::mnp::hex_encode(range) 把连续 range range 中的每个字节编码成小写十六进制串。 ::fast_io::mnp::hex_encode(digest)
::fast_io::mnp::hex_encode_upper(range) 把连续 range range 中的每个字节编码成大写十六进制串。 ::fast_io::mnp::hex_encode_upper(digest)

12. 加密哈希文件操纵器

把加密哈希上下文（例如 sha256_context、md5_context）适配成输出文件，从而可以增量地对数据做哈希。

操纵器 说明 示例
::fast_io::mnp::as_file(hashctx) 把 hashctx 包装成窄字符（char）输出文件，用于增量哈希。 print(::fast_io::mnp::as_file(ctx), data);
::fast_io::mnp::u8as_file(hashctx) 把 hashctx 包装成 char8_t 输出文件。 print(::fast_io::mnp::u8as_file(ctx), u8"data");
::fast_io::mnp::was_file(hashctx) 把 hashctx 包装成 wchar_t 输出文件。 print(::fast_io::mnp::was_file(ctx), L"data");
::fast_io::mnp::u16as_file(hashctx) 把 hashctx 包装成 char16_t 输出文件。 print(::fast_io::mnp::u16as_file(ctx), u"data");
::fast_io::mnp::u32as_file(hashctx) 把 hashctx 包装成 char32_t 输出文件。 print(::fast_io::mnp::u32as_file(ctx), U"data");

一个完整的哈希示例： 


#include <fast_io.h>
#include <fast_io_crypto_hash.h>

using namespace fast_io::io;

int main()
{
    try
    {
        ::fast_io::sha256_context ctx;
        print(::fast_io::mnp::as_file(ctx), "Hello, fast_io!\n");
        ctx.do_final();
        println(::fast_io::mnp::hash_digest(ctx));
    }
    catch throws (::std::error e)
    {
        ::fast_io::perrln(e);
        return 1;
    }
    return 0;
}

小结

::fast_io::mnp:: 中的每个操纵器都是一个轻量、可平凡复制的包装对象，只作用于它所包装的值。不存在需要恢复的流状态，也没有需要记住的全局格式串。
