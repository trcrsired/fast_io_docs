第11章: I/O

English

概述

本章讲 fast_io 的 I/O 系统 — 这是整个库的核心。我们将学习如何进行文件 I/O、如何为打印和扫描定义自定义类型、如何使用操纵器、理解操作层，并接触操作系统文件 API 的每一个层次。

重要前提：本章假设你运行在拥有完整文件系统访问权限的标准宿主环境中。如果你运行在应用沙箱里（例如移动应用沙箱、浏览器 WASM 沙箱、容器限制），或者运行在 freestanding 环境里（例如没有操作系统的嵌入式系统、内核开发），那么关于文件 I/O 的许多前提都不再成立。我们会在后续章节讨论这些特殊环境。
