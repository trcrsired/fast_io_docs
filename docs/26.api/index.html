Status

This reference is being written. The tutorial chapters are complete and remain the authoritative explanation of how the library is meant to be used; this section will grow into the lookup layer beside them.

The goal is not a dump of every declaration. It is a map from a task to the type and function that performs it, with the ownership, buffering and error contract stated explicitly.

Until the Reference Is Complete

Use the chapter that introduces the feature. Each page states the header, the type, the operation and the failure contract, and the chapter index is the fastest way to find the right page:

  • Ch11: I/O — devices, operations, formatting, files and processes.
  • Ch23: Coroutines — the asynchronous model.
  • Ch24: Reflection — compile-time reflection.
  • Ch20: Freestanding — what changes without an operating system.

If a declaration is missing here, do not guess from the name. Read the introducing chapter first; the reference will link back to it when the entry is written.
