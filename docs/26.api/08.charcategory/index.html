Ch26.8: char_category

中文（简体）

1. What char_category Is

fast_io::char_category is a compile-time, locale-independent character classification layer. It answers the questions that <cctype> answers in the C locale, plus fullwidth/halfwidth and a few path/HTML helpers, without a locale object and without a function call at runtime when the compiler can fold it.

Every predicate is constexpr and noexcept. The layer accepts the character types fast_io uses: char, wchar_t, char8_t, char16_t and char32_t.

static_assert(::fast_io::char_category::is_c_digit('7'));
static_assert(!::fast_io::char_category::is_c_space('x'));

3. Case and Width Conversion

The conversion functions are function objects, not macros, and they are also constexpr:

Entry Effect
to_c_lower(ch) Map an uppercase character to lowercase where the C locale defines the mapping.
to_c_upper(ch) Map a lowercase character to uppercase.
to_c_halfwidth(ch) Map a fullwidth punctuation or form to its halfwidth form where defined.
ranges::to_c_lower(first, last[, proj]) Apply the mapping to an iterator/sentinel range; returns the final iterator.
ranges::to_c_upper(range[, proj]) Apply the mapping to a range; returns a borrowed iterator.
ranges::to_c_halfwidth(range[, proj]) Apply halfwidth conversion to a range. 

char c{'A'};
c = ::fast_io::char_category::to_c_lower(c);   // 'a'

::fast_io::string s{"Hello"};
::fast_io::char_category::ranges::to_c_upper(s);

The range versions accept a projection, so they compose with a member accessor: 


::fast_io::char_category::ranges::to_c_lower(
    first, last, [](auto const &e) { return e.initial; });

4. char_category_traits

char_category_traits<family, negate> turns a family into a callable predicate. It exposes family, is_negate and char_is(ch), and its operator() calls char_is. This is the form to store in a table or pass to an algorithm.

using digit_pred = ::fast_io::char_category::char_category_traits<
    ::fast_io::char_category::char_category_family::c_digit, false>;

static_assert(digit_pred::char_is('5'));
static_assert(!digit_pred{}( 'x' ));

5. Module and Header Boundary

The fast_io module exports:

  • char_category_family and char_category_traits;
  • to_c_lower, to_c_upper, to_c_halfwidth;
  • the ranges::to_c_lower, ranges::to_c_upper and ranges::to_c_halfwidth range forms;
  • is_dos_file_invalid_character.

The individual is_c_* predicates are header-side today. So are is_html_whitespace and is_dos_path_invalid_prefix_character. They are all available through #include <fast_io.h>; if you are using the module, include the header for the predicate you need until the export list is extended.

Not a locale. char_category is not the fast_io.i18n layer. It is the C-locale classification and conversion layer. Use the locale module when the answer must change with the user's locale.

Key Takeaways

  • char_category is compile-time, locale-independent character classification.
  • The core predicates mirror the C <cctype> families, plus fullwidth/halfwidth, HTML whitespace and DOS file-name validation.
  • to_c_lower, to_c_upper and to_c_halfwidth are constexpr function objects; the ranges:: forms apply them to a range with an optional projection.
  • char_category_traits<family, negate> is the callable, storable form of a family.
  • The module exports the traits, the three conversion objects, their range forms and is_dos_file_invalid_character; the individual is_c_* predicates remain header-side.
  • This layer is not a locale; use fast_io.i18n for locale-dependent formatting.
